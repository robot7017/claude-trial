# Claude 试用

这个仓库用来试用 Claude 的两个功能：**写代码**和**日常询问**。试用结束后，根据效果决定要不要采购。

## 试用时间

- 两天，具体日期在群里确认
- 每天两类问题加起来最多 8 个

## 怎么提交问题

1. 打开本仓库的 **Issues** 页面，点 **New issue**
2. 选择模板：**代码** 或 **日常询问**
3. 按模板填写后提交

一个 Issue 只问一件事。

### 代码问题需要写清楚

- 背景：在做什么项目，用什么语言或框架
- 要求：想实现什么功能，或者要修什么问题
- 相关代码、报错信息（贴在代码块里）

### 日常询问需要写清楚

- 背景：为什么想问这个
- 问题本身
- 希望回答是什么形式，比如简短结论、详细解释、列要点

## 回复放在哪里

- **日常询问**：在 Issue 下面评论回复
- **代码**：短代码直接贴在评论里；长代码放进 `answers/` 文件夹，文件名以 Issue 编号开头（如 `answers/3-xxx.py`），评论里附链接
- **追问**：在同一个 Issue 下继续评论，会在下一轮一起回复

## 什么时候回复

每天统一处理两次：

- **12:00**（北京时间）
- **21:00**（北京时间）

在这两个时间点之前提交的问题，会在当轮回复。回复完的 Issue 会关闭；如果还有问题，可以重新打开或继续评论。

## 注意

本仓库是公开的，任何人都能看到 Issue 内容。请不要提交密码、密钥、个人信息，或不能公开的代码和数据。

## 试用结束后

请从这三个方面评价：

1. 代码能不能直接运行，或者只需要稍作修改
2. 日常询问的回答是否准确、有用
3. 自己平时大概会多常用，适合哪种套餐
