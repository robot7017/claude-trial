# Claude 试用

这个仓库用来试用 Claude，主要试两件事：**写代码**和**日常询问**。试用结束后，根据效果决定要不要采购。

试用时间：两天，具体日期在群里确认。问题数量不限。

## 怎么提交问题

1. 打开本仓库的 **Issues** 页面，点 **New issue**
2. 选一种模板：
   - **代码问题**：写代码、改代码、排查报错
   - **日常询问**：日常问题
   - **项目任务**：涉及整个项目的较大任务，比如加功能、找 bug、重构、读懂代码结构
3. 选择用哪个模型回答（见下面「模型怎么选」），按模板填写后提交

一个 Issue 只问一件事。大任务建议拆成几步，分几个 Issue 提，比如先「读懂结构」，再「加功能 A」，再「写测试」。

## 项目内容放在哪里

两种方式都可以：

- **直接放进本仓库**：放在 `projects/<项目名>/` 文件夹里。可以自己提交，也可以把文件发给我代为上传
- **放在自己的仓库**：在 Issue 里贴链接。私有仓库需要把 `robot7017` 加为协作者

> ⚠️ **本仓库是公开的**，放进来的代码、文档和 Issue 内容任何人都能看到。请不要放密码、密钥、个人信息，或不能公开的代码和数据。不能公开的项目，请用第二种方式。

## 模型怎么选

| 模型 | 特点 | 适合 |
|---|---|---|
| **Claude Opus 5.5**（默认） | 能力强，适合复杂任务 | 项目、较难的代码问题 |
| **Claude Sonnet 5.5** | 速度和能力比较均衡 | 一般的代码问题和日常询问 |
| **Claude Haiku 5.5** | 速度最快，适合简单问题 | 简单、快速的问答 |
| **Claude Fable 5.2** | 目前最强的模型 | 特别难的问题 |

不确定就选默认的 Opus。

Fable 不包含在当前套餐里，每次使用都要额外付费。选 Fable 的问题，会先和提问人确认后再回复。

## 回复放在哪里

- **日常询问**：在 Issue 下面评论回复
- **代码**：短代码直接贴在评论里；长代码放进 `answers/` 文件夹，文件名以 Issue 编号开头（如 `answers/3-xxx.py`），评论里附链接
- **项目**：改动代码时，在项目所在的仓库开 Pull Request，可以逐行查看改了什么，确认后再合并；分析类的回答写在 Issue 评论里
- **追问**：在同一个 Issue 下继续评论，会在下一轮一起回复

每条回复开头都会注明用的是哪个模型。

## 什么时候回复

每天统一处理两次：

- **12:00**（北京时间）
- **21:00**（北京时间）

在这两个时间点之前提交的问题，会在当轮回复。回复会按所选模型分批处理，所以从整点开始陆续发出，可能稍有延迟。项目类任务不一定当轮做完，会在 1–2 轮内先给出第一版。回复完的 Issue 会关闭；如果还有问题，可以重新打开或继续评论。

## 试用结束后

请从这三个方面评价：

1. 代码能不能直接运行，或者只需要稍作修改
2. 日常询问的回答是否准确、有用
3. 自己平时大概会多常用，适合哪种套餐
